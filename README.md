# RentSense

**RentSense** is an ML-powered property rental platform that predicts fair market rent and helps users find or list properties with data-driven price recommendations.

---

##  Screenshots

### 1. ML Fair Rent Calculator
Predicts estimated rent and confidence ranges based on property size, location, amenities, and proximity to stations.

---

##  Key Features

- 🔮 **ML Rent Predictor:** Machine learning model (Random Forest) predicting fair rental rates.
- 🏢 **Property Marketplace:** Interactive search and filters for tenants to find fair-price rentals.
- 💡 **AI Price Recommendation:** Helps property owners set realistic rent based on market data.
- 📊 **Analytics Dashboard:** Real-time charts showing location-wise price trends and demand.

---

##  Tech Stack

- **Frontend:** React.js, Tailwind CSS 
- **Backend:** Node.js, Express.js
- **Machine Learning:** Random Forest Regression
